# Release 1.1.0

This curated English-only showcase adds causal temporal-validation examples, isolated strategy-book accounting and persistent server-runtime documentation, plus a synthetic cost comprehension exercise. The complete platform and production configuration remain private.

Validation: eight deterministic public tests cover cost conservation, invalid quote rejection, quantity reuse and temporal leakage boundaries. Synthetic examples contain no live performance data. No credentials, private history, provider account identifiers, user records or deployment snapshots are included.

The public demo remains a static execution cost laboratory. Server robots, authentication, private market-data access and the full backtest engine are described at the architecture level and do not run in this public site.
