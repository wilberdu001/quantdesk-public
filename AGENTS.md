# Public portfolio boundary

- This repository is a curated recruiting showcase. Keep the complete platform, unpublished strategies, backtest framework internals, research notebooks, account data, credentials and deployment identifiers in the private quantdesk project.
- Include only deliberately selected generic implementations, synthetic fixtures, reproducible execution-cost experiments, architecture explanations and a standalone demonstration.
- Clearly label synthetic demonstrations and execution assumptions. Do not present these experiments as strategy alpha or live trading performance.
- The owner authorizes pushing reviewed changes to https://github.com/wilberdu001/quantdesk-public (public). Do not publish material from the private project by copying its full tree or Git history.
