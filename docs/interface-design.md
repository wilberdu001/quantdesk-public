# Research interface design

Research tools should make provenance and uncertainty easier to inspect. The private platform's refreshed workspace uses the existing dark palette, spacing, borders and typography rather than introducing another visual system.

- Data trust: three decision-oriented summaries, followed by a source table and explicit event-versus-collection timestamps.
- Temporal validation: separate training, validation and held-out return cards, equity sparklines, drawdowns and a horizontally contained fold table. Full methodology stays in a disclosure.
- Strategy books: budget summaries, fee-inclusive inventory tables, a labeled order form, distinct robot controls and readable audit logs.
- Learning: visible progress, numbered steps, explicit evidence categories, synthetic cost inputs and accessible answer feedback.

Forms have persistent labels, visible focus indicators and consistent primary/secondary actions. Tables scroll within their panel. Narrow screens stack cards and controls; the private stylesheet is scoped to the added workspace pages so established tools keep their layout. Simulation labels and source limitations remain visible. Account reset and late-response guards still clear private output.

This public repository demonstrates the same presentation principles in its synthetic learning exercise. No private screenshots, user state, data entitlements, strategies or production deployment identifiers are published.
