# Guided learning with evidence

The private learning route connects six steps: source verification, a synthetic transaction-cost exercise, a successful paper fill, a completed backtest, held-out validation and a risk review. Rejected and pending orders do not complete the fill checkpoint. Data mode and evidence time remain attached to each completion.

Actual tool completion is distinguished from a self-check. The cost question explicitly uses synthetic quotes; the risk question teaches that pausing a robot preserves inventory and that an exit still needs valid market conditions. Progress is user-scoped, schema-checked and versioned through the existing state service. Account switches clear tool output caches and invalidate late responses.

The public demo includes only the synthetic cost question and needs no login. It does not publish private account state, provider credentials, server identities or production screenshots. Learning completion is educational evidence, not certification, financial advice or an authorization to trade.
